---
Notebook Requirements: dino_mask_alignment.ipynb

Goal: Qualitatively evaluate DINOv3-based candidate mask filtering — given a source object crop,
measure cosine distances to SAM3 agent candidate crops on the destination frame, and visualize
which candidates survive different thresholds.

Success metric: approach accelerates SAM3 Agent (fewer candidates passed to MLLM) without
removing the target mask, thereby not degrading output quality.

Configuration (3 sub-steps, each prints guidance for the next)

Step 4.1 — Data path
- DATA_DIR — root containing {take_uid}/{camera}/{frame}.jpg + annotation.json
- DINOV3_DIR — absolute path to the local dinov3-main repo (used for torch.hub.load)
- On run: print table of all available takes, objects, cameras, frame counts

Step 4.2 — Sampling
- N_SAMPLES — how many (take, object, src_frame, dst_frame) pairs to draw randomly
- RANDOM_SEED — for reproducibility
- DIRECTION — "ego->exo", "exo->ego", or "both" — which transfer direction to sample
- On run: print selected samples as a numbered table (idx, take_uid, object, src_cam, src_frame,
  dst_cam) — user reads this table to fill in object descriptions in Section 5b

Step 4.3 — Filtering parameters
- COSINE_THRESHOLD — cosine distance cutoff in DINOv3 embedding space; candidates above are
  filtered (cosine distance = 1 - cosine_similarity, range [0, 2]; typical range [0, 1])
- DINO_MODEL_NAME — local model name, e.g. "dinov3_vitl16" (passed to torch.hub.load)
- VIS_STRIDE — show every Nth sample in the visualization loop (default 1 = all)
- On run: confirm parameters

Model Loading (Section 6)

DINOv3 — load from local repo via torch.hub:
    dino_model = torch.hub.load(
        repo_or_dir=DINOV3_DIR,   # e.g. "/path/to/dinov3-main"

SAM3 — load image model and processor, wrap call_sam_service (no Ollama required):
    from sam3 import build_sam3_image_model
    from sam3.model.sam3_image_processor import Sam3Processor
    from sam3.agent.client_sam3 import call_sam_service as _call_sam_service_orig
    from functools import partial

    sam3_model = build_sam3_image_model(bpe_path=bpe_path, device=device)
    sam3_processor = Sam3Processor(sam3_model, confidence_threshold=0.5, device=device)
    call_sam_service_base = partial(_call_sam_service_orig, sam3_processor=sam3_processor)

No Ollama/MLLM setup needed for Sections 7–9. The optional Section 10 agent run requires
Ollama; its setup cell is self-contained and can be skipped.

---
Crop Specification

The crop passed to DINOv3 must satisfy:
- Computed from the tight bounding box of the binary mask (source GT mask for source crop;
  candidate mask for destination crop)
- Expanded to a square by extending the shorter side symmetrically, clamped to image bounds
- Resized so that both spatial dimensions are the nearest multiple of 16 (DINOv3 patch size)
  — e.g. a 100×80 square → 96×96 (nearest multiple of 16 ≤ 100)
- No background padding added; the square expansion uses actual image pixels, ensuring only
  the object region (plus minimal context) is seen by DINOv3

Rationale: DINOv3 ViT uses 16×16 patches. Crop dimensions that are multiples of 16 avoid
partial patches at the boundary, giving a clean patch grid covering only the object.

Helper Functions

def decode_mask(rle_str: str, H: int, W: int) -> np.ndarray
    """RLE string → bool array at (H, W)."""

def mask_bbox_square(mask: np.ndarray) -> tuple[int, int, int, int]
    """Return (x1, y1, x2, y2) square bbox centered on mask, clamped to image bounds."""

def snap_to_patch_grid(side: int, patch_size: int = 16) -> int
    """Return largest multiple of patch_size that is <= side."""

def make_dino_crop(rgb: np.ndarray, mask: np.ndarray) -> np.ndarray
    """Square-expand mask bbox, snap to 16-px grid, crop. Returns uint8 array."""

def embed_crop(crop: np.ndarray, dino_model, device) -> np.ndarray
    """
    Preprocess crop with ImageNet normalisation, run DINOv3, return unit-norm CLS token
    embedding as float32 array. Uses model.get_intermediate_layers(..., return_class_token=True).
    """

def cosine_distance(a: np.ndarray, b: np.ndarray) -> float
    """Cosine distance (1 - cosine_similarity) between two unit-norm vectors. Range [0, 2]."""

def render_candidate_grid(dst_rgb, candidates, src_embedding, dino_model,
                          device, threshold) -> plt.Figure
    """
    One row of subplots — one per candidate crop — each titled with:
    index | SAM3 score | cosine dist | KEEP / DROP
    Green border = kept, red border = dropped.
    Figure title includes threshold value.
    """

def render_overlay(rgb: np.ndarray, pred_mask: np.ndarray, gt_mask: np.ndarray,
                   alpha: float = 0.45) -> np.ndarray
    """Blend pred (red), GT (green), overlap (yellow) — same as reference notebooks."""

Candidate Generation and DINOv3 Ranking (Section 7)

For each sample, using only the SAM3 image model (no MLLM, no Ollama):

  1. Call call_sam_service_base(image_path=dst_frame_path, text_prompt=OBJECT_DESCRIPTIONS[i],
       output_folder_path=tmp_dir)
     → load resulting JSON → pred_masks (RLE list), pred_scores, orig_img_h, orig_img_w

  2. Decode each candidate mask (RLE → bool array, resize to image dims if needed)

  3. Embed the source GT mask crop: src_emb = embed_crop(make_dino_crop(src_rgb, src_gt_mask), ...)

  4. For each candidate mask: cand_emb = embed_crop(make_dino_crop(dst_rgb, cand_mask), ...)
     Compute dist = cosine_distance(src_emb, cand_emb)

  5. Compute GT IoU for each candidate: iou_i = compute_iou(cand_mask, dst_gt_mask)

  6. Apply filter: kept = [i for i, d in enumerate(distances) if d <= COSINE_THRESHOLD]

  Per sample, track:
  - n_candidates_before, n_candidates_after
  - distances: list of cosine distances, one per candidate (in SAM3 score order)
  - gt_ious: list of GT IoUs, one per candidate
  - false_negative: bool — True if argmax(gt_ious) not in kept
  - best_kept_iou, best_dropped_iou

  Print candidate count, distances, and false_negative flag before visualization.

Primary diagnostic plot — cosine distance vs GT IoU scatter:
- One point per candidate across all samples
- X axis: cosine distance to source crop; Y axis: GT IoU
- A negative correlation confirms DINOv3 ranks correct candidates closer to the source
- Color: kept (steelblue) vs dropped (tomato); shape: GT-best candidate marked with ★
- Threshold line overlaid as a vertical dashed line
- This is the single most important output of the notebook

Secondary plots:
- Cosine distance histogram: all candidates, GT-best highlighted, threshold line overlaid
- SAM3 score vs cosine distance scatter: checks whether SAM3's own confidence correlates
  with DINOv3 distance (if yes, filtering adds no value over score thresholding alone)

Data Contract Assumptions (from CLAUDE.md)

- annotation.json structure: masks[object_name][camera][frame_str] → RLE
- GT masks stored at 1408×1408, must be resized to image size before use
- Image paths: DATA_DIR/{take_uid}/{camera}/{frame_str}.jpg
- Ego cameras contain "aria" in their name; exo cameras do not
- Source frame selection: pick the annotated frame with the largest GT mask area (same as reference notebooks)
- Destination frame: a randomly chosen annotated frame from the opposite-viewpoint camera of the same object/take
